Architecture overview

Factory Inventory Management System

A two-tier demo app. A Vue 3 single-page app talks over HTTP/JSON to a FastAPI service. The service loads mock JSON files into memory at startup and filters them on each request. There is no database and no real authentication.

Data flow: changing a filter

Example: a user picks a warehouse on the Dashboard.

  1. The user changes a dropdown in FilterBar

    This sets a ref in useFilters.js. The refs live at module level, so every view shares the same filter state.

  2. The view reacts and builds a filter object

    getCurrentFilters() returns { warehouse, category, status, month? }. The Time Period selector is sent as month.

  3. api.js sends the requests

    Values equal to 'all' are dropped. Dashboard fires four calls in parallel: summary, orders, inventory, backlog.

  4. FastAPI filters the in-memory lists

    apply_filters() does exact matches on warehouse and case-insensitive matches on category and status. filter_by_month() does a substring match on order_date. Quarter keys (Q1-2025…) expand to three months.

  5. Aggregation and validation

    The summary endpoint computes totals on the fly, for example inventory value = Σ qty × unit_cost, and low stock = qty ≤ reorder point. List endpoints are checked against their Pydantic response_model.

  6. The view stores the raw data and derives the rest

    Responses go into refs such as allOrders and inventoryItems. Computed properties produce the KPIs, tables and SVG charts.

Known gaps and quirks

These are things I noticed while reading the code. Useful to know before changing anything.

  • Missing endpoints: api.js calls /api/tasks and /api/purchase-orders, but main.py doesn't define them. A live check of /api/tasks returned 404.
  • Unrouted view: Backlog.vue exists but isn't registered in the router in main.js.
  • Duplicated base URL: Reports.vue uses axios directly with its own copy of the URL instead of going through api.js.
  • Data resets on restart: everything lives in memory, so any future write endpoints would lose data when the server restarts.
  • Hardcoded quarters: QUARTER_MAP only covers 2025.
  • Mock auth: useAuth.js returns a fixed demo user. There's no login.
  • Open CORS: allow_origins=["*"], which is fine for local demos only.
